# 医療面接タイマー

医療面接練習用のシンプルなWebタイマー。iPadのSafariでホーム画面に追加して、アプリのように使えます。

## 特徴

- 任意の時間を設定してカウントダウン(初期値 7 分)
- 残り 1 分でオレンジ色に切替(過度に焦らせない配色)
- タイマーは複数追加可能(医療面接以外の用途にも)
- 設定はブラウザに保存(リロードしても残る)
- iPadでスリープしないよう Wake Lock 対応
- 白背景・黒文字・大きな数字、Noto Sans JP

## 使い方

`index.html` をブラウザで開くだけ。デプロイ後はそのURLを iPad のホーム画面に追加すると便利です。

## デプロイ

Vercel に GitHub リポジトリを連携するだけで公開できます(ビルド設定不要、Framework Preset = Other)。
